# orangeflim 产品需求（PRD）

版本：v0.16；文档集U1，2026-11-07。职责：业务范围与验收，不定义第二套技术协议或任务表。

## 0 产品当前基线

直接基于原版OpenFilm v0.3.0 desktop/Studio，新增原App卡片首页，不另建界面系统。品牌orangeflim；无新增业务侧栏；项目/模板/Skills/素材源沿原能力。平台Windows首发、Mac仅Apple Silicon arm64规划。主仓D:/dev/orange/dev，原生接口优先，当前状态见execution/status.json。

剪口播：默认所选口播、多选、可切本工程全部人声；ASR时间戳文字/空白候选→人选择试听确认→音画字幕同步剪合→同工程保存、一键Undo。原片不变；无字不等于静音。原CLI缺现成剪口播命令，需要原链最小扩展（16/07），不能另建时间线。

业务确认/覆盖/授权以00为准；本稿业务不代表代码已实现。本轮只统一文档，后续新goal须明确范围。

## 1 产品定位与目标

### 1.1 定位

**已确认 C01–C03、C26、C27、C36、C48：** 以完整OpenFilm desktop/Studio主工程承接橙子交接业务，面向企业内部小组，保留原业务价值与界面布局方向，以film承载编辑，以既有Fission成果承载批量创作。旧已上线方案继续运行，本PRD不授权改动其代码、数据、配置或发布；新旧不是直接在现网边运行边替换。未来对外产品方向保留，当前不建设对外收费体系。

目标用户是使用授权素材进行短视频创作、批量混剪、素材加工和审核的内部成员。小组具体人数、审核人员安排及管理权限尚未确定，不照抄旧 Demo 的员工数或角色枚举。

### 1.2 产品目标

1. 打通授权素材取得、加工人审、素材中心、批量创作/编辑、草稿保存、视频/剪映交付和确认入库的完整链路。
2. 同一素材、账号、工程和任务在各板块含义一致，避免重复建库、状态错乱、串号或丢失来源。
3. 人工决策、Agent 干活、审核审查；自动化减少重复劳动，不代替人的最终业务决定。
4. 允许本地创作和文件留在本地；云上传是经确认的后续动作，不是本地素材可用的前提。
5. 从“能演示”提升为有明确权限、失败恢复、版本兼容、日志追踪和发布证据的产品。
6. 首版即沉淀可复用的个人模板/技能，按用户归类保留创作经验与修订依据，在人工确认和权限边界内持续改进，形成公司的知识、数据与技能资产（C49/C50）。

稳定、安全、鲁棒性通过验收条件和故障恢复来衡量，不承诺绝对无故障或绝对安全。具体耗时、并发、恢复时间和容量阈值待实测后提出。

## 2 用户角色与决策责任

**已确认 C08、C25、C37：人工决策 → Agent 在获准范围执行 → 审核审查。** 人工也可以直接编辑工程。C45明确允许同一人决策和审核，不强制第二审核人；Agent仍不能替人确认。

| 参与者 | 责任 | 不可混淆的边界 |
| --- | --- | --- |
| 创作者/人工决策者 | 确定任务、素材范围和关键要求，编辑、选择交付方式 | 拥有个人工程不等于拥有任意云素材的使用权 |
| Agent | 按请求批准或全权限模式，在获准范围内选片、编排、处理字幕/配音、执行编辑及自动检查 | 不扩大账号或IP授权，不替代四类人工最终确认，不把自动检查伪装成人审 |
| 审核角色 | 审查切片、标签及需要审核的成果，记录结果 | 自动执行成功或模型高分不等于审核通过 |
| 公司管理员 | 查看和管理本公司的沉淀经验、模板和技能，承接离职保留治理 | C52/C53已确认；不因此获得全部原工程/媒体或替他人绑定智尚的权限，管理动作留审计 |
| 管理/运营角色 | 承接邀请、额度、运行维护等管理职责 | 其他具体权限待定，不以运营角色默认代替公司资产管理员 |

允许同人审核已经确认，不再列为待决定。公司管理员对沉淀经验/模板/技能的查看和管理已由C52确认，离职保留按C53；原工程/媒体等其他资源的管理员权限、双模式交互和复核触发按D06/D07/D10收敛；IP撤回后的不可见/不可请求已由C57确定，D09仅细化传播、离线及交付边界。Ethan说明云管家入库后还会有审核，但该外部工作流和API尚未验证；它不取消橙子上传前核对内容、标签、本人目标及所选项的确认。工程负责权限校验、冲突控制、撤销和记录，不为每一步内部计算增加审批弹窗。

### 2.1 账号权限 素材使用范围与云绑定

授权按以下含义区分。C57明确素材/IP授权及撤回是核心业务；这里不是网络IP地址，也不另行假定一套未确认的IP申请审批流程：

- **账号权限**：当前橙子用户能看、改或操作哪些个人资源；是否能访问本人云绑定下相应资源。不是绑定电脑IP地址。
- **素材/IP授权**：某账户对具体素材及其内容的访问和使用范围，覆盖已知的素材、配音音色、音乐等来源限制；撤回后该账户不可见、不可再请求。下载、个人工程归属或Agent全权限均不构成继续授权。
- **Agent任务范围**：用户明确让Agent做什么，不是新的素材产权或云账号。
- **云绑定**：属于橙子账号，不属于本地剪辑/生成任务；只有云端操作记录本人目标及绑定版本，避免任务期间换绑而误投。

每个用户的本地工程、产物和云端关联记录分别隔离。素材中心统一的是入口，不是把多人的资产混成一份；本人云账号有权读取的共享来源素材仍按第三方实际范围展示，不因此取得他人橙子个人工程或成品。

### 2.2 Agent执行授权与人工最终确认

**已确认 C56：** 提供“请求批准”和“全权限”两种模式。前者对未获准动作请求批准，可按明确任务/批次授权，不要求每一步内部编辑都弹窗；后者允许Agent在获准范围内连续执行、编辑和自动检查，不逐项请求执行批准。两种模式均受本人账号、素材/IP权限及公司规则约束，不能自授更多权限。

以下四类动作始终需要人的最终确认：素材审核、云上传、知识正式沉淀、团队共享。Agent可以准备候选、清单、修改建议或执行已获人工确认的操作，不能替人点击确认或写入“人工已确认”。一次明确确认可覆盖所选多条，但不自动覆盖新增条目、改变的内容或新的目标范围；同一人可以完成审核。

这里的“云上传”指FR-08向云管家提交切片、审核通过的AI补充素材或成片，须确认具体内容、标签及本人目标。C58所需公司业务记录同步不是逐条弹窗的媒体交付，也不授予原始媒体外发权限。模型输入须在已明确的公司数据外发授权范围及模型服务策略内；范围不明则不发送，Agent全权限不扩大该范围，也不默认给每次合法模型调用增加一次上传审批。

**工程建议，待验证：** 授权记录范围、模式、授权人及有效状态，支持暂停/收回；执行记录关联具体授权与工程修订，自动检查与人工确认分开。模式默认值、提示方式、授权持续时间和编辑冲突处理由设计提案，不伪装成已确认参数。

### 2.3 IP撤回与公司记录保留

**已确认 C57/C58：** 授权素材撤回后，对应账户不可见、不可再请求；公司保留全部业务操作数据，不删除。撤的是账户对素材的访问与使用许可，不是删除素材、操作历史或审计证据，也不是向其他账户或管理员自动开放内容。

业务要求覆盖素材中心、最近使用、搜索结果及详情，不能只隐藏列表却仍从直链、缓存、历史工程、模板或Agent取回已撤素材。个人备注、评级、选用、工程来源、任务、审核/批准、交付和积分记录仍由公司保留；受限账户不能靠历史记录重新看到被撤内容。

**工程建议，待验证：** 按账户和资源范围传递撤权状态；原片、代理/缩略图、转写及派生引用同步限制，受影响工程保留结构和无内容泄露的无权提示，不静默换源。收到撤权后隔离相关在途结果，恢复和备份不复活旧权限。业务操作记录区分本地待同步与公司已核验留存，保存原有身份、版本和来源链；诊断日志轮转不删除这些业务记录。

撤权前已成功、撤权后仍由橙子管理的历史成片或剪映包，也不能仅凭“归本人”或“历史成功”继续预览、下载、重传其中的受限内容；须核验当前来源权限或已明确且有效的独立授权，未证明时不放行。成功事实和公司记录仍保留，不改写为从未成功；系统外副本的处理不属于可承诺的远程收回。

**尚待评审/验证的边界：** 断网设备无法即时获知服务端新撤权，已经交付到系统外的明文视频/剪映文件也不能承诺远程追回。撤权传播时效、受限资源离线有效窗口、在途停止及已交付派生物的独立授权边界按D09收敛；不把这些困难当作允许已撤账户继续访问的规则，也不宣称已经满足“离线即时撤权”。C40在授权有效时仍成立，不未经讨论把全部本地操作改成持续联网。

公司留存业务数据不等于默认全量上传本地原始媒体，不改变换机边界；公司持久化、访问范围与恢复的实现须有证据，不能把设备上的唯一副本称为公司已保留。

### 2.4 本轮账号与离线授权澄清

C68/C69/C72：各角色均可处理本人有权原工程/媒体；转组或失去资格后保留资产/历史而不延续原组权限，云换绑后旧绑定云权限失效，仅展示当前绑定实际有权内容。留存不自动变更所有权，也不开放他人资产。C81进一步明确首版不开放普通用户的原工程/素材共享，以个人为单位；只有管理员可确认将有相应共享权限的公开素材加入公司内部案例库，不能借此读取所有人私有原媒体。离职知识归公司，知识模板技能管理与原工程/媒体读取分开。

C85：启动或重启必须联网向橙子完成第一方鉴权，失败只能停留在登录/网络重试界面，不能凭缓存进工作区。已登录运行中断网，C40下已准入任务可完成，本地编辑/保存可继续；未准入的新组合、云请求等待网络。账号会话与素材/IP许可分别有效，已知撤权立即限制，不因本地计时无限续期。工程提出授权有效期与撤权传播/时钟异常方案；不默认断网强退、清草稿或离线冷启动自动恢复执行。系统外已导出明文不能靠退出登录保证收回。

### 3.2 不纳入首版默认承诺的内容

- 可从橙子提交新标签创建；云端成功并确认真实标签引用后再同步使用。AI 新词、临时 ID、待处理请求不是正式标签。
- 标签真源不等于工程、ASR 分析和橙子账号也交由智尚管理。未上传内容可选择云字典标签，不因此强制上传。
- 承接按产品、人物、原句/文案和标签找素材、定位源片段并预览/试听后选用的业务；检索结果仍须符合本人当前权限，不仅限本人上传内容。

- 区分资料原有评级、个人评级、AI候选评分；保留各自来源和旧枚举，不自动换算或覆盖。
- 领取资料、文件就绪、解析就绪、人审状态及使用权分开；缺解析可进入待补齐区，不将下载成功统一冒充可直接创作。
- 按C57限制已撤权账户的展示与请求，按C58保留公司业务记录。同步刷新、历史引用和直接访问不能绕过权限。

**工程建议：** 同名标签不等于同一标签；保留实例/公司/适用类型/父级/个人或公共作用域。云端更新刷新正式缓存，未提交选择保留并重新核验，不自动覆盖云端。

**C71补充：** 切片、成片优先继承适用云标签；无云标签时本地模型识别候选，经人工核对，复用已有正式ID或沿C35云端创建成功后同步。候选不成为本地平级正式真源，离线保留待同步意图，标签同步不自动上传媒体。多来源继承仍核验分类/作用域和接口限额；云端变更能力及精确标签维护字段见04及供应商研究附录，本次已成功核读原文；真实权限、幂等及字典变更传播仍待验证。

### FR-03 素材工厂与人工核对

**已确认：C04–C06、C30/C31、C37、C60。**

- 对有权使用的确定原片版本做转写、候选切片、评分、摘要与标签建议。

#### AI生成补充素材

**已确认 C60：** 生成新画面用于补产品展示、人物或场景镜头，不替代云管家素材。生成结果先进入待审核区，人工核对内容并确认后，作为正式可用素材进入素材中心，供超级混剪和创作中心选择使用；未经审核或被拒绝的候选不得自动参与混剪或编辑选材。进入素材中心不要求先上传云管家，也不自动公开或团队共享。

需要上传时，审核通过的生成素材另进入上传清单，核对内容、标签及本人目标后单独人工确认，沿用FR-08。素材审核与上传批准分别记录，Agent全权限不能替代其中任一确认。正式标签仍来自云管家；AI生成来源作为资源元数据保留，不另建一套正式标签。

**工程建议，待验证：** 复用素材工厂的生成/审核入口、公共模型与任务服务，而不是另建独立素材库。保存创作需求、获准参考输入、模型调用/实际输出版本、文件校验、人工审核及来源关系；新生成或修改成新版本后不能沿用旧内容的审核。可用性同时要求真实文件、人工审核和有效使用权，模型返回成功不等于素材合格；提示词、任务ID或随机种子不能代替实际视频，也不能直接充当混剪内容指纹。

**待定工程方案：** 具体生成服务与输入方式、镜头长度/画幅及参考资料的最小支持集合，由工程比较后提案；不擅自加入数字人、口型同步或整条成片全AI替代能力，不要求Ethan逐项选择底层参数。

**待验证：** 产品/人物一致性、场景镜头可用性与视觉缺陷，文件/人审/权限门禁，两创作入口复用，成本/耗时与异步未知结果对账。模型输入外发与IP权限沿用第2节；质量不满意的重做/计分仍按D23待收敛，不自动把人审拒绝等同供应商调用失败。

### FR-04 超级混剪 Fission 有序批量创作与共享去重

**已确认：C03/C07、C18–C24、C40。**

1. 读取根目录下子文件夹，以数字序号形成场景组，如 1开场、2产品、3讲解、10结尾。组间叙事顺序固定，重组或重试不能把开场转到结尾。
2. 允许同一素材用于多条成片。禁止同批或同组历史中完全相同的完整组合；一项实际内容不同即可，包括只换配音或 BGM，不要求画面必须改变或达到变化比例。
3. 在实际素材、区间、音轨等内容确定后，渲染前联网查重并预占；不能仅凭路径列表或“缓存没命中”判断已准入。
4. 遇到重复先自动重组；仍不足时集中引导二次编辑，不逐条弹窗。二次编辑后产生的新组合仍需重新准入。
5. 重复、待编辑、仅保存工程和未成功结果不计视频完成。允许保留成功项主动结束，不强制补满；目标 100、成功 80 仍为 80/100。
6. 无需人工编辑的结果可直接导出视频或剪映草稿；需要编辑时进入 film，不要求先渲染 MP4。
7. 已准入且依赖齐全的条目断网可继续本地完成，联网后补登记。服务端占用和恢复设计不得把可能已交付的组合仅因失联释放给别人。

**C63–C68补充已确认：** 每组抽取数量和单片内重复可配置；主动结束不再派发并直接停止在途，保留此前完成；合格剪映单出口完成进入历史、未完成不打包凑数；纯编码/输出分辨率允许再次导出，不新增混剪内容成功；独立创作中心成果不入组内去重；成员转组后资产/历史留存而旧权限不保留。既有Fission能力须复验，不据用户说明宣称已运行通过。

**工程提案/待验证：** 重号/空组/不足提示、有界候选预算、是否提供穷举的资源安全方案、有效内容规范化与转换降级、停止与完成竞态、持久占用及迟到回执。C83已确认“重做”和“关联补充批次”两种选择均提供；不把取消请求等于进程已退出。

**C83补充：** 重做是明确发起下一次创作，不清空原成功/去重历史；补充批次保留与原批关系，目标为本次补充数量，两批各自显示实际成功，聚合不重复计数。故障重试复用原冻结方案，已有成果重导出不当新创作；重做重新选材/编辑所得新组合仍需准入，原样重生成被历史拦截，不因换批次ID重置去重。物理batchId/runId策略由07冻结。

**C42补充：** 用户按自己的素材和配方创作，不必先填创作单，也不默认限制同一商品/SKU或额外必备镜头。只落实用户自己选定的组序、数量/时长配置及明确要求；不以系统自造规则拦截合法创作。

**工程建议：** 一次执行失败重试引用原冻结方案，不重新随机抽样；准入前的重复重组与执行后的故障重试是不同动作。不保存全部笛卡尔积，仅对实际候选和准入/成功结果留账。

### FR-05 创作中心 film 人工与 Agent 编辑

**已确认：C02/C07/C08、C26、C37；具体编辑集合待 D05 验证。**

- 承接素材中心或 Fission 方案，保留橙子的业务入口与个人归属。

#### 声音供给与真人录制需求

**承接业务已确认 C59，实现待验证：** 用户先检索已有语音并试听复用；需要新配音时选择登记的授权音色生成TTS；也可导入本人有权使用的本地录音、音乐和音效，完成分类、试听、裁剪、音量、淡入淡出和音轨排布。声音资源保留归属、来源/许可及实际文件版本，公共与个人可见范围不混用。

#### 真人录制结果的加工与复用

**已确认 C61/C62：** 同时支持纯音频和真人口播视频，分别作为配音素材和视频素材；两类均先人工审核，再进入素材中心。真人录制结果可做ASR识别、编辑、LLM分析建议及JEV评分；处理后的内容可作为素材进入film创作中心，Fission超级混剪可选择复用，不自动塞入每个混剪批次。人工素材审核、当前IP使用权、本人归属及公司记录留存继续执行；LLM建议和JEV评分不能代替人审，也不自动产生云上传批准。

**工程建议：** 接入有权使用的真实录制文件 → ASR转写及时间对应 → 校正识别稿、编辑片段/字幕 → LLM建议与JEV评分辅助选用 → 人工核对确认 → 素材中心 → 两创作入口。按任务需要调用模型，不把每次本地编辑都变为一次在线分析；素材进入正式可选区仍需人审、文件及使用权满足要求，不以模型高分自动放行。缺分析或不适用的评分要明确显示，不能伪装成已评分或人审通过。

原录制、转写稿、人工修订、剪辑结果及分析/评分分别保留版本。修改识别文字或字幕不会自动改动真人原声；如需改变实际口播内容，应明确补录、重剪或采用另经授权的配音版本，不能把改稿冒充已经重录。LLM建议由人选择采纳，JEV评分作为内容筛选依据，不新增强制分数门槛或把文字评分宣传成已证明的声音/画面质量评分。

素材中心保存统一素材身份及来源，两入口引用确定可用版本；支持范围和用途按C62执行：

| 已确认输入 | 素材用途 | 创作中心与超级混剪的复用方式 |
| --- | --- | --- |

## 8 断网 部分成功与完成口径

### 8.1 已确认的断网规则

C85区分阶段：离线启动/重启不进入工作区，不自动开始任务；已登录运行中断网才适用以下C40本地续跑。鉴权服务不可达与智尚/模型单独不可达分别提示，第三方故障不自动等同橙子账号失效；不删除本地数据。

| --- | --- |

| Fission 已准入、授权有效且无需新的在线输入 | 本地继续执行、校验和交付，成功事实持久保存；共享历史联网后补登记 |

C57与离线的实现边界：撤权的业务结果已经确定，但离线设备发现服务端变化有时延，传播和受限资源离线窗口须验证及评审。不能将旧缓存、历史批准或“已准入”视为永久授权，也不在未验证时声称能追回系统外文件。公司业务记录离线期间可靠待同步，收到公司持久化核验后才能显示已保留（C58）。
