`unclassified` 99.51% 远超 50% 阈值，**必须兜底**，但口径要分层，不能只放宽现有 `NAMED`：

1. **第一层（最高性价比）**：把“数字日期/编号”当批次候选 —— 覆盖 50.22% + 中文日期 2.80%，例 `12.13_…`、`0130-…`、`12月18日…`。风险：这些是**素材日期不是批次号**，与 `20261106` 这种批次号语义不同，需要 Lead 明确“伪批次”是否允许混入批次列表（建议单列 `derived` 标记，不污染 `batches`）。
2. **第二层**：把“分组词 + 序号”当分组兜底 —— 19.61% 含分组词、39.45% 以 `_n` 收尾，可在缺日期/产品时归入“未归档”伪批次，用分组词建组（`茶干`/`汤色`/`包装`/`规格`/`冲泡` 等），这一层几乎无歧义。
