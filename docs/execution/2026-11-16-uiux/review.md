1. dev 是 Electron 应用，`4757` 端口返回的是桌面窗口页（`apps/desktop/shell/dist`），纯浏览器打开会因缺 Electron 桥（`app.hello()`）白屏。因此**用 `--remote-debugging-port=9333` 重启了 dev**（`node scripts/start.mjs --no-build --remote-debugging-port=9333`），再用 playwright-core `connectOverCDP` 驱动真实窗口。重启使原内存登录态失效，已用 `POST /api/auth/sign-in` 重新登录（`ok:true, kind:active`，凭证未打印）；该进程需要环境变量 `ORANGE_AUTH_CONFIG_FILE=D:\dev\orange\.dev\auth-runtime.json`，否则登录返回 `configuration-required`。
2. **dev 目前仍带 9333 调试端口在跑**。若不需要，用不带该参数的启动命令重启即可（数据未受影响：工程、素材索引、云管家绑定都还在）。
3. 三个工程 tab 共存于一个窗口，多个 WebContentsView 会同时存在；截图取自当前置前视图。未做任何写操作（未导入、未下载、未解绑、未新建），仅点击导航。

### B1. 合集 → 分组下素材列表恒为空，成组素材不可见、不可用
- 截图：`07b-group-materials.png`（进入「油弃乌龙茶 / 外包装」后）

- 建议：进入分组时按 `videoIds` 拉取（或按组条件重新 refresh）；拿不全时给出明确的分页/加载按钮，而不是把「已加载 0 条」当成结果。

## 二、明显级

### M1. 同一个素材中心，抽屉与全宽两种形态差异过大
- 截图：`05-cloud-videos.png` vs `12-materials-workspace.png`
- 抽屉：2 列、约 104px 小卡、操作是 hover 才淡入的 3 个裸图标（`+ ✎ ↓`，`opacity-0 group-hover:opacity-100`）、元数据挤成一串无分隔（`云端未下载素材普洱茶类茶膏户外朱柏宇2025-03-180:092.0 MB下载 0收藏 0`）。

- 建议：抽屉形态至少保留「标题 + 时长 + 一个主操作」，元数据用分隔符或 chips，别做成一整串文本。

### M2. 合集视图密度太低，「暂无封面」占据大半张卡

## 五、专项判定明细

### 1. 筛选残留
- 云管家（抽屉与全宽）筛选区实际控件：`input[data-filter="search"]`（placeholder `标题或描述`）、`button[type=submit] 应用`、`select[data-filter="author"]`（`cloud:own 我的素材（我上传的）` / `cloud:company 公司素材（全部）`）。
- 对 `来源/主类目/一级/二级/状态/时长/排序/公共标签/标签` 扫 `label|button|select|option|th|summary`：**0 命中**。
- 结论：**残留已清除**，符合「只剩搜索 + 作者」。唯一遗留的空 `<option value="cloud:own" disabled>` 在未绑定时禁用，属正常。
- 建议：顺手把「应用」按钮与搜索做成回车即搜（现在回车也提交，但按钮与输入框在窄屏被挤散）。
