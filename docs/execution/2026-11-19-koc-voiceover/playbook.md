# KOC 口播混剪：节奏、合规、价值罗盘、场景与标准文案

日期 2026-11-19 · 面向 OrangeFilm（Studio + Fission）的策划与执行手册

> 这份不是方法论散文，是**可以照着执行、也可以照着校验**的东西：每一节都对应到我们已有的工具或明确要补的东西。
> 外部事实都标了来源；数字来自二手研究与我们自己语料的实测（67 035 条素材的时长分布）。

---

## 0. 一句话结论

口播混剪能不能成，取决于三件事：**时间以音频为准**（先把话说完说完多久，再裁画面）、
**画面服务句子**（一句一镜、切点在换气处）、**说法不越线**（暗示走场景与体感，不碰功效词）。
我们缺的从来不是素材或模型，是"把这三件事串成一条可校验的流水线"。

## 1. 真实口播剪辑长什么样（节奏数字）

三档节奏，来自公开的节奏规范与实测（[pacing-rules](https://raw.githubusercontent.com/feicaiclub/video-spec-builder/main/references/pacing-rules.md)、
[huashu-art-motion](https://github.com/nexu-io/open-design/blob/de6d2c072a18dfef80ecad4a455b31f0d5aca090/skills/huashu-art-motion/references/explainer-grammars.md)）：

| 档 | 每镜头 | 每分钟镜头数 | 大转场 | 留白 | 旁白密度 | 适用 |
|---|---|---|---|---|---|---|
| **hook 型（高密度）** | 0.8–2.0 s | 30–60 | 每 4–6 s | <5% | 1.5–2 字/秒 | 抖音 15–30 s、信息流、带货开头 |
| 教程型（中密度） | 2.0–5.0 s | 15–30 | 每 10–15 s | 10–15% | 2–3 字/秒 | 产品演示、60–90 s |
| 纪录型（慢） | 3.0–8.0 s | 7–20 | 每 20–30 s | 20–30% | 1.5–2.5 字/秒 | 品牌片、vlog |

**我们做的是第一档。** 一条 15 s 的带货口播，落到数字上：

```
口播字数      45–60 字（3–4 字/秒；4.5 字/秒是"不停顿"的上限，含停顿约 3.5–4）
镜头数        6–9 个（≥5 是客户底线，不是上限）
单镜时长      1.5–2.6 s
换镜频率      每 1.5–2 s 一刀；大转场（甩镜/黑场/推拉）每 4–6 s 一次
首帧          0.4 s 内必须出"人/产品/动作"，不能是黑场或空镜
字幕          烧录，整句切入切出，白字 50 px 黑描边 10 px（竖屏 1080×1920），不做动画
```

**四条硬规则**（决定"画面对不对得上声音"）：

1. **一句一镜**：镜头跟着句子走，不跟着音乐拍子走；
2. **切点落在换气里**：上一句说完 → 停顿 0.15–0.3 s → 切 → 下一句开口。切在字中间是最明显的业余感；
3. **停顿是资产**：说完重话留 0.8–1.5 s 给脸；包袱后定住 ≥0.9 s；
4. **音乐不驱动画面**：BGM 只垫情绪与节奏感，不要求每刀落在拍点上（那是卡点视频，不是口播）。

## 2. 合规红线（食品/茶叶，抖音与微信小店）

规则原文要点（[抖音电商食品饮料宣传规范](https://school.jinritemai.com/doudian/web/articlev0/110096)、
[抖音电商学习中心·医疗相关](https://school.jinritemai.com/doudian/wap/articlev0/aJnXfEc1N4sC)、
[微信小店带货短视频宣传规范](https://www.10100.com/article/36329543)）：

| 类别 | 不能出现 | 严重度 |
|---|---|---|
| 医疗保健功效 | 减肥、瘦身、燃脂、祛湿、排毒、清热解毒、利尿、防癌抗癌、增强免疫/抵抗力、降火、调理肠胃、助消化、促进肠道蠕动、通便、改善睡眠、护肝、壮阳、丰胸、增高 | 下架/限流 |
| 病症暗示 | 二甲双胍、胰岛素、糖友、升糖指数、三高、脂肪肝、结节、病号服、停药 | 下架/限流（**茶叶素材提"二甲双胍"是被点名的案例**） |
| 绝对化 | 国家级、最高级、最佳、第一品牌、顶级、极品、独一无二、万能 | 下架 |
| 黑五类暗示 | 悄悄变瘦、穿小一码、肚子小一圈、CUP、二次发育——**明示暗示同罚** | 下架/封功能 |
| 效果承诺 | 三天见效、七天见效、立刻、秒变、一喝就、立竿见影 | 高风险，需证据或改说法 |
| 价格/稀缺 | 虚构原价、全网最低、仅此一天、最后 N 件 | 价格欺诈 |
| 贬低同行 | 比 X 好用、吊打、碾压、别家都是 | 不正当竞争 |

**合规的暗示怎么写**（这是我们的核心能力，规则允许、平台不判、用户听得懂）：

| 想暗示 | ❌ 违规说法 | ✅ 安全说法（走场景/体感/生活） |
|---|---|---|
| 瘦 | 悄悄变瘦、穿小一码 | 「过完年我饭局多，下午那杯就是我的开关」「裙子还是那条裙子」 |
| 皮肤好 | 素颜也白、祛黄 | 「这个冬天我懒得化妆，就靠早上这一杯热乎的」「老祖宗用的细糠，我们现在喝进肚子里」 |
| 精神/气色 | 提神、抗疲劳 | 「下午三点不开会的时候，我泡这一颗，人一下就回来了」 |
| 送礼/体面 | 最高级的礼 | 「丈母娘喝过一次，后来每次去都问我带没带」 |
| 稀缺/紧俏 | 最后 10 件、错过再无 | 「这一批是去年晒的，今年雨水多，量就这些」（真实信息才可用） |

## 3. 价值罗盘（三步法）

### 第一步 · 拆自己的价值

| 支撑类型 | 要回答的问题 | 小青柑（示例） |
|---|---|---|
| 功能支撑 | 它具体解决什么"场景问题"（不写功效） | 一颗一泡、不用称茶、办公室 30 秒出汤 |
| 信任支撑 | 我有什么你没有：产地、年份、工艺、背书、联名 | 新会核心产区三年陈；迪士尼联名；某平台同类目销量第一（需截图凭证） |
| 情感支撑 | 情绪/精神/身份 | 「成年人的下午茶，是一个人待着的十分钟」 |

### 第二步 · 顾客与竞争视角

- **顾客为什么买**：送礼体面 / 自己喝着舒服 / 办公室方便 / 长辈认这个 / 看别人喝想试
- **还有什么需求没被满足**：不知道怎么泡、怕买贵、怕不正宗、怕难喝、怕麻烦
- **竞品在说什么**：都在讲"正宗新会""古法日晒"—— 所以我们的差异要落在**场景与用法**上，而不是再喊一次产地

### 第三步 · 翻译成标准文案（完整句子 + 可视化场景）

这一步是过去最容易断的地方：梳理完了没有变成"标准文案"，也没有变成"标准画面"，所以每次都要重新想。
现在固定成一张卡：

```
场景（应用/动作，不是地点）：
人物（谁、什么状态）：
前 3 秒钩子（现场声/动作/一句反常识）：
文案（完整句子，逐句一行，每句 ≤ 12 字）：
画面（每句配什么镜头，写明素材类型：人物/手部/包装/汤色/环境/对比）：
字幕（与文案同句，切点同帧）：
元素（转场/贴纸/文字版式）：：
BGM（情绪 + BPM 区间）：：
配音（音色 + 语速）：
合规自检（claim-check 结果）：
```

## 4. 场景的定义（不是地点，是"正在做什么"）

我们的场景库（可直接当筛选标签用）：

| 场景 | 触发词 | 对应镜头 | 对应 BGM |
|---|---|---|---|
| 办公 | 工位、下午三点、开会、加班 | 手部冲泡、电脑旁、窗外 | 轻电子、无鼓点、70–90 BPM |
| 居家 | 沙发、阳台、追剧、晚上 | 暖光室内、杯子特写 | 钢琴/吉他，60–80 |
| 通勤 | 地铁、包里、随身 | 包内取出、手持 | 环境声为主 |
| 待客 | 客人、泡一壶、亲戚来 | 多人手部、茶盘、倒茶 | 民乐/轻爵士 |
| 送礼 | 礼盒、长辈、丈母娘、迪士尼 | 礼盒开箱、递出、笑脸 | 温暖弦乐 |
| 独处 | 一个人、放空、睡前 | 空镜、窗边、蒸汽 | 极简、留白多 |
| 仪式感 | 每天、第一杯、开关 | 固定机位重复动作 | 有记忆点的短旋律 |
| 爱茶 | 回甘、喉韵、汤色、年份 | 汤色特写、叶底 | 安静，留环境声 |
| 天气 | 冬天、入秋、回南天 | 窗外雨、热气 | 低频铺底 |

**功效属于场景**：不能说"祛湿"，但可以说"回南天，我每天早上泡这一颗"—— 暗示由场景承载，不由形容词承载。

## 5. 三个案例拆解

### 案例 A · 闷泡茶（6 款 = 6 个场景）

一款茶一个场景，不做"全家桶"文案：

| 款 | 场景 | 一句话文案 | 画面 | 暗示 |
|---|---|---|---|---|
| 1 | 办公提神 | 「下午三点，我泡这一颗，人一下就回来了」 | 手部冲泡 + 电脑 + 窗外 | 状态回来（不说提神） |
| 2 | 待客 | 「亲戚来，我不泡茶包，泡这个」 | 茶盘、多人手部、倒茶 | 体面（不说高级） |
| 3 | 送礼 | 「迪士尼联名，丈母娘第一次没挑我」 | 礼盒开箱、递出、笑脸 | 关系（不说最好） |
| 4 | 独处 | 「一个人的晚上，一颗能泡三泡」 | 暖光、蒸汽、窗边 | 陪伴（不说治愈） |
| 5 | 爱茶 | 「三年陈，柑皮先香，茶汤后甜」 | 汤色、叶底、掰柑特写 | 专业（不说正宗到极致） |
| 6 | 运动后 | 「跑完步不喝冰的，泡这个」 | 运动服、水汽、手部 | 自律（不说减脂） |

**6 款对应 6 个场景**，是"同一产品不同人群"的标准做法：素材可复用、文案不重复、每款都能单独投。

### 案例 B · 温润滋养（"茉莉花加普洱，我坚持每天喝一杯，悄悄惊艳所有人"）

这句的问题在"悄悄惊艳所有人"——它指向**外貌变化**，是黑五类暗示的典型。改成场景+体感：

```
❌ 茉莉花加普洱，我坚持每天喝一杯，悄悄惊艳所有人
✅ 茉莉花加普洱，我每天下午一杯，喝到第三个月，同事问我最近是不是换了护肤品
   （把"变好看"交给别人的嘴，不是自己的结论）
```

完整脚本：

```
场景：办公 · 下午 · 连续第三个月
钩子：同事探头问"你是不是换护肤品了"（现场声）
文案：① 茉莉花加普洱 ② 我每天下午一杯 ③ 第三个月 ④ 同事问我换了什么护肤品 ⑤ 我说没有
画面：① 干茶特写 ② 手部冲泡 ③ 桌面日历翻页 ④ 同事侧脸/工位 ⑤ 本人摇头笑
字幕：与文案同句，切点同帧
BGM：轻钢琴 70 BPM，第 4 句起加一层弦乐
配音：女声，3.5 字/秒，句间停顿 0.25 s
合规：claim-check 通过（无功效词、无绝对化、无黑五类）
```

### 案例 C · 暗示素颜（"老祖宗用的细糠""这个冬天悄悄安排上，过年惊艳所有人"）

原句同样踩线（"惊艳所有人"=外貌变化承诺）。安全版：

```
✅ 老祖宗用的细糠，我们现在喝进肚子里
✅ 这个冬天我不太化妆了，早上这杯热乎的先下肚
✅ 过年回家，我妈说我脸色比去年好（把判断交给别人）
```

画面要求：**不拍脸对比、不拍前后**（前后对比本身就会被认为是功效展示）。改为拍：手、杯、蒸汽、窗、衣领、冬天的街道。

## 7. 落到我们产品：一条可校验的流水线

```
用户一句话
  → ① 价值罗盘（三步表）→ 标准文案卡（第 3 节模板）
  → ② claim-check（本地，block/warn/hint + 改写建议）
  → ③ TTS 出真实时长（qwen / minimax）→ ffprobe 量每句
  → ④ 素材检索（bge-base + 向量包）按句子语义 + 时长筛（≥句子时长）
  → ⑤ shot-plan 排片（一句一镜、裁切起点、变速、空镜填缝、总时长校验）
  → ⑥ VTT 字幕轨（与句子同一份数据，切点同帧）
  → ⑦ BGM（库检索或生成）+ 元素（转场/贴纸/文字）
  → ⑧ Studio 时间线 / Fission 渲染
  → ⑨ 校验报告（时长/镜头数/画幅/碎镜/音画对齐/合规）
```

已具备：②④⑤⑥⑦⑧ 的零件（claim-check、检索、shot-plan、caption-tracks、library.search、providers、时间线）。
缺的：③ 的"TTS→时长→回填"、⑨ 的校验器、以及把 ① 的模板做成 Studio 里的一张"任务卡"。

## 8. 验收标准（这条流水线算不算做成）

一条 15 s / 9:16 / ≥5 镜头的口播混剪，必须同时满足：

1. 总时长 15.0 ± 0.3 s；
2. 镜头数 ≥5，单镜 1.2–8 s，无 <1.2 s 碎镜；
3. 每句口播都有对应镜头，**句子时长 ≤ 镜头显示时长**（不允许画面先跑完）；
4. 空镜只出现在无台词处；
5. claim-check 无 block、warn ≤1（且每条 warn 有证据或已改写）；
6. 字幕与句子一一对应，切点与换镜同帧 ±40 ms；
7. 首帧 0.4 s 内出现人/产品/动作。

这七条就是 `shot-plan` + `claim-check` + 校验器要签的字。它们过了，用户才不需要在剪辑软件里返工。

## 补：为什么"先违规再改"是对的（2026-11-19 追加）

我原来的顺序（先合规、再包装）有一个隐患：它让人从一开始就在"能说什么"的框里写，力度先掉一半。
operator 的顺序更实际——**先写出最有力度的那句（草稿期允许越线），再照着风险点改写**。理由是：

1. **违规是上下文**，不是一个词。同一句"过完年惊艳所有人"：没有人名、没有产品、没有画面时它只是形容词；
   配上"这个月我每天喝"和前后对比的镜头，它就是外貌变化承诺。所以判断必须看整句 + 谁在说 + 配什么画面；
2. **改写要保住信息点与情绪点**，而不是删掉。删掉的文案没有转化，改写的才有；
3. **两道闸**：草稿阶段只标注（`mode: 'draft'`，不阻断），发布前必须 `mode: 'publish'` 复检通过。

代码已经这么做：

```
checkClaims(text, { mode: 'draft' })    → ok 永远 true，blocking/needsRewrite 如实给，附 why + rewrite
checkClaims(text, { mode: 'publish' })  → blocking > 0 就不许发
```

实测同一句：

```
「喝了一个月，裤腰就松了，过完年惊艳所有人」
draft    ok=true   blocking=2  rules=koc-black-five, causal-effect
publish  ok=false  blocking=2
改写方向：拆掉因果（事实与体感并列）＋ 把"变好看"交给别人的嘴（同事问我换了什么护肤品）
```

### 改写三式（从命中项直接生成）

| 式 | 做法 | 例 |
|---|---|---|
| 并列式 | 拆掉"所以/就/让"，事实与体感并列 | 「我下午泡一颗」／「胃里暖暖的」 |
| 转述式 | 把结论交给第三方（同事、家人、评论区） | 「同事问我最近换了什么护肤品」 |
| 场景式 | 用应用场景承载暗示，不指向身体结果 | 「回南天，我每天早上泡这一颗」 |

## 补：Fission 的界面该长什么样（对用户，不是对开发者）

我上一条说"Fission 不该有界面"是错的：它是**给人手动批量出片**的工具，界面就是它的主战场。
错的是"表单铺满文字"，不是"有界面"。人在这件事上要看三样东西：**这批片子会成什么样、哪条有问题、改完重出**。

一屏只做三件事：**看、判、重出**。

```
┌ 批量出片 ────────────────────────────────────────────────┐
│ 项目：小青柑礼盒          预设：抖音竖屏 15s（9:16）  ▾   │
│ 12 条 · 已完成 9 · 待处理 3            [ 全部重出 ]       │
├──────────────────────────────────────────────────────────┤
│ ▣ 01  小青柑-办公下午茶     首帧缩略图   15.0s 9:16 6镜 ✅ │
│ ▣ 02  小青柑-送礼迪士尼     首帧缩略图   15.2s 9:16 5镜 ⚠️ │
│        └ 第 3 句"丈母娘第一次没挑我"没有对应镜头（还差 1.1s）│

│ ▣ 04  温润滋养-茉莉普洱     首帧缩略图   15.1s 9:16 5镜 🚫 │
│        └ 合规：「喝了一个月，裤腰就松了」是因果暗示，点开看改写 │
└──────────────────────────────────────────────────────────┘
```

规则：

1. **列表就是预览**：每行一张首帧缩略图 + 一行诊断；不做"点进去才知道错在哪"；
2. **失败说人话**：「第 3 句没有对应镜头（还差 1.1s）」而不是 `PLAN_NO_CANDIDATE`；
3. **红/黄/绿三色只表示一件事**：能不能发（画幅时长镜头数合规全部通过才绿）；
4. **一键重出**：改完素材或文案，只重出受影响的那几条，不是整批；
5. **不做参数表单**：参数进"预设卡"（抖音竖屏 15s / 视频号横屏 30s / 口播 60s），选一次就行；
6. **差异可见**：改前/改后两版并排，标出改了哪一句、哪一镜。

这一屏的东西我们全都有数据：`shot-plan` 出时长/镜头数/慢放，`claim-check` 出合规，`caption-tracks` 出字幕。
缺的只是把它们拼成这一屏，以及"哪条失败、为什么、怎么改"的那一句人话。
