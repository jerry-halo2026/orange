# 千川商品卡素材：规格、结构、审核与批量策略

日期 2026-11-19 · 与 `batch-design.md`（批量）、`playbook.md`（文案与节奏）配套

> 场景变了：**巨量千川 · 商品卡投放素材**。这是**付费广告**，不是自然流量。
> 所以三件事跟着变：审核更严（广告法 + 平台广告审核）、素材消耗更快（跑量需要持续供给）、
> 判重看的是**六层指纹**（见 `batch-design.md` 第 11 节），不是"观众觉不觉得像"。

---

## 1. 规格（商品卡素材的硬约束）

| 项 | 值 | 说明 |
|---|---|---|
| 画幅 | **9:16 竖屏**，1080×1920（或 720×1280） | 商品卡位是竖屏全屏 |
| 时长 | **9–30 s**（主投 12–18 s） | 太短讲不清卖点，太长完播掉 |
| 首帧 | **必须有产品**（不是黑场、不是纯文字） | 商品卡首帧即封面，也是 pHash 那一层的输入 |
| 字幕 | **必须有**（烧录） | 投流场景大量静音播放 |
| 音轨 | 配音 + BGM（BGM 音量约 -12 dB） | 音频指纹独立一层，BGM 也要换 |
| 结尾 | **CTA + 产品**（"一颗一泡""这一批量就这些"） | 不能出现"点击下方/私信我"（诱导点击） |
| 素材数量 | 一个计划下 **>5 条**才好起量 | 我们做 100 条就是素材池 |
| 文件 | 每条独立导出（不同 md5） | 文件层最便宜那一层，但必须过 |

## 2. 结构模板（15 s 版）

```
0.0–3.0s  钩子：产品入画 + 一句反常识 / 一个动作
          （首帧就要有产品；这句决定 CTR）
3.0–9.0s  卖点 ×2：产地/年份/一颗一泡/口感，每 2–3 s 一个镜头
9.0–13.0s 场景或信任：办公下午茶 / 送礼 / 晒场 / 别人说的一句话
13.0–15.0s 收束：产品 + 一句 CTA（不诱导点击）
```

- 每句一镜（`shot-plan` 已实现）；切点落在换气处；
- 全程字幕（`caption.write` 从 plan 的 cues 生成）；
- 镜头时长 ±0.3–1 s 抖动、70% 硬切（时序层指纹）；
- 裁切/缩放 1.1 左右、轻微旋转 <1°（视觉层指纹，肉眼几乎看不出）。

## 3. 审核红线（千川 · 食品/茶饮）

`claim-check` 现在覆盖（`packages/openfilm/src/claim-check.mjs`）：

| 规则 | 类别 | 严重度 |
|---|---|---|
| `medical-effect` | 功效词（减肥/祛湿/助消化/增强免疫…） | block |
| `disease-hint` | 病症暗示（二甲双胍/糖友/三高…） | block |
| `causal-effect` | 因果暗示（喝…就…/坚持…所以…） | block |
| `absolute` | 绝对化 + **价格类绝对化（全网最低/最低价）** | block |
| `koc-black-five` | 黑五类暗示（悄悄变瘦/穿小一码/惊艳所有人） | block |
| `ad-solicit` | **诱导点击与站外引流（点击下方/加微信/扫码/二维码）** | block |
| `ad-guarantee` | **效果保证（无效退款/根治/立刻见效）** | block |
| `time-promise` | 时间承诺（三天见效） | warn |
| `ad-price-claim` | 价格与促销真实性（原价/划线价/买一送一） | warn |
| `compare` | 贬低同行 | warn |
| `marketing-cliche` | 营销套路词（伤完播） | hint |

**素材层面还要注意**（渲染前人工过一眼，我们不自动判断）：第三方平台 logo/水印、二维码、
明星代言口径、资质与检测报告画面、价格与活动周期一致性。

## 4. 批量策略（100 条怎么用）

投流素材不是"越像越好"，也不是"越不一样越好"，而是：

```
素材池要足够大（一个计划 >5 条起量），且**彼此在多层上不同**，
否则同计划内素材互相抢量、同账号历史判重、跨账号被判低质重复。
```

对应 `planset.json` 的轴（按破坏哪几层排序）：

| 轴 | 破坏的层 | 100 条里的建议分布 |
|---|---|---|
| 文案 take（文案 ⊗ 音色） | ④ ASR 文本 | **≥10 种说法** |
| 素材与剪辑节奏 | ②③⑤ | 每条不同素材组合 + 时长抖动 |
| 裁切/调色/画中画 | ②⑤ | 每条一组轻微不同参数 |
| 封面（首帧） | ② 封面 pHash | 每条来自不同镜头 |
| 标题/话题（投放侧） | 文本层 | 投放时轮转，不由渲染决定 |
| 导出参数 | ① 文件层 | 29.97 / 30 / 50 fps 轮转 |
| BGM | ④ | 相邻不同 |

**发布前必须跑 `dedupe-check`**（见 `batch-design.md` 第 11 节）：本地算 100 条的 md5 / 3 帧 pHash /
镜头时长序列 / 音频指纹摘要 / ASR 文本，两两比出矩阵。不承诺过审（阈值不公开），
但保证不拿近似重复的 100 条去撞墙。

## 5. 与自然流量素材的区别（一句话）

| | 自然流量 | 千川商品卡 |
|---|---|---|
| 判据 | 内容质量 + 完播 + 互动 | **CTR/CVR/ROI**（素材是出价的一部分） |
| 首帧 | 可以叙事铺垫 | **必须产品 + 卖点**（首帧就是封面与素材卡图） |
| CTA | 可弱 | 必须有，但不能诱导点击 |
| 时长 | 15–60 s 常见 | **9–30 s**，主投 12–18 s |
| 素材寿命 | 长 | **短**（跑量后迅速衰减，需要持续供给 → 这就是 100 条的理由） |
| 判重 | 同样六层 | 同样六层，**同计划内互相抢量更致命** |
