# 执行证据入口

现行事实只由status.json路由；任务ID/依赖/生命周期只由project-tasks.json登记，phase1-plan-status仅指向计划与注册表；产品验收状态只由pilot-readiness.json记录。本轮文档一致性回执为documentation-unification.json。

其它带日期的receipt、review、inventory、manifest均是原subject/commit/time的不可变证据，不是当前状态或新的执行授权。它们的next/旧数量/旧路径只描述当时，不得自动恢复为新任务。原生源码与导入证明见discovery来源索引；本机私有备份不进公共仓。
