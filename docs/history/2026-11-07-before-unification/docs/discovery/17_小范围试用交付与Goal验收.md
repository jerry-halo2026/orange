# 小范围试用交付与 Goal 验收

状态：2026-11-07 交接提案。用户要求下一会话以goal推进到可小范围测试；本会话只整理文档，不创建goal、不开发、不发布。本稿定义交付判据，不代替PRD业务、07增量契约或实际验收证据。

## 1. 目标和范围不能混淆

目标是原版OpenFilm主工程上可实际安装、登录、创作、保存重开、交付和恢复的orangeflim Windows内部试用候选，不是dev服务器能开、首页截图或演示壳。产品平台仅Windows与macOS Apple Silicon arm64；一期交付Windows，保留Mac arm64适配/构建，不承诺Mac本期验收，排除Intel Mac/Linux客户端/Universal包。CI运行在Linux不等于支持Linux客户端，也不因此删除原上游通用代码。

现有T01–T10只是第一段原版主链，不等于PRD全部首版。全首版以PRD FR-01–FR-11和V01–V61及剪口播增量验收；有缺项只能如实叫局部候选。若Ethan选择缩小试用，必须列明具体不开放功能/用户范围和替代入口，获明确批准后登记，不能由Agent自动缩减。

“可交付候选”与“发给测试人员”分开：本地构建、安装和验收形成候选；分发、正式更新通道、main/tag/发布或生产切换仍另批。不能为goal完成而私自触发官方release或借用上游证书、账号和更新源。

## 2. 路线与依赖

1. **R0 防漂移准入**：14接手；核最新Git/源pin/目标环境/授权；16原生IO/API/命令逐项引用；07只登记必要增量；修订后的一期计划作为任务来源。实际N5a后动态并行，不等M1。
2. **R1 原版主链**：T01–T10，原首页/Auth、智尚适配、本地素材复用、Fission隔离/真实方案/Studio交接、剪口播。先原生入口和真实持久化，再UI接线，禁止第二套mock产品。
3. **R2 首版补齐**：下表U包按所消费的契约/真实资源派发；开工前写最小任务卡、确切文件/签名/失败测试，独审。不是先造全首版框架或一次冻结所有字段。
4. **R3 候选验收**：最新实际组合提交在D盘正式候选区验证；完整矩阵/支持范围/安装恢复/故障/安全和全分支非作者审查。
5. **R4 试用准备**：Ethan核对试用范围、人员、已知限制、反馈/停用/恢复责任；形成签收记录。真实分发或main/tag另批，不自动随完成发生。

## 4. 何时可称完成

- 完整首版候选：PG01–PG12全部适用项通过且证据对应同一集成候选；基于现有原版dev起点，经独审/门禁串行合入dev后，对实际dev头复验并保留远端提交/安装包/恢复记录。任何豁免都须Ethan批准的明确范围记录。不得由Agent自签N6/替人点击素材人审；这不是main/tag或发布批准。
- 局部候选：缺本人绑定/模型/硬件/上传授权时其它工作继续；可展示本地成果但总目标未完成。若用户明确缩小试用范围，受限入口禁用/说明，另记录缩小后的验收集；不能静默删除FR。
- Goal状态按当时工具规则处理；预算耗尽、外部阻塞、Agent口头完成、单分支绿色、文档齐备均不是完成。不能长期空跑同一阻塞；报精确所需输入并保留恢复点，不私自扩大权限。
- 不保证某个日期/成本内完成，不编造缺失实机/远端保护/云真实结果。检测到偏离原版、未登记协议、并发写集冲突或越权，停止受影响任务，修正任务卡后继续无关任务。
