# OrangeFilm trademarks

The code in this repository is licensed under [MIT](LICENSE): use it, change it, ship it. The license covers the code,
not the OrangeFilm name and logo. This page says how you can use them, so that people always
know what comes from the OrangeFilm project and what does not.

## You can

- Say what your work does with OrangeFilm: "made with OrangeFilm", "an OrangeFilm film", "works with OrangeFilm", "for the
  OrangeFilm format".
- Refer to OrangeFilm in articles, talks, tutorials, courses and videos.
- Fork this repository and keep the name while you work on changes you mean to send back.
- Redistribute unmodified releases under their own name.

## You can't, without written permission

- Name a modified version, a product, a hosted service or a company "OrangeFilm", or anything easily confused with it.
  A fork you publish as your own needs its own name.
- Use the OrangeFilm logo for your own product or service, or a logo that looks like it.
- Suggest that the OrangeFilm project made, endorses or supports your work when it does not.
- Use "orangefilm" in a domain name, package name or account name in a way that looks official.

## Questions

Write to support@orangefilm.example. If you are not sure whether a use is fine, ask: most are.
