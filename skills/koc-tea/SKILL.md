# KOC 文案（茶饮层）

这一层只管**这个品类能说什么**。通用写法与改写三式在 `koc-writer`。

## 何时用

- 写小青柑/乌龙/普洱/花茶这类目；
- 需要判断"这句话在这个品类算不算功效暗示"；
- 需要挑场景（办公 / 送礼 / 独处 / 待客 / 溯源）。

## 品类红线（比通用层更严的地方）

| 不能说 | 为什么 | 换成 |
|---|---|---|
| 祛湿 / 助消化 / 降三高 / 增强免疫 | 食品不得宣称保健功能 | 描述口感、香气、工艺、场景 |
| 喝了一个月，裤腰就松了 | 因果暗示功效（说成"经历"也算） | 并列事实：泡的动作 + 可验证细节 |
| 三年陈所以更养胃 | 因果 + 功效 | 只讲年份与工艺事实 |
| 送礼最有面子 / 全网最低 | 绝对化、价格承诺 | 讲具体场景与谁说过什么 |

## 场景库（详见 references/scenes.md）

办公下午茶 / 送礼 / 独处夜间 / 待客 / 溯源码 / 开箱。
