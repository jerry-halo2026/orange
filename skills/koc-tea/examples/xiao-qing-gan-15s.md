# 例：小青柑礼盒 · 15s 竖屏口播（9:16，≥5 镜头）

> 这是"从需求到可拍"的完整一份。每一步都能被检查：文案过体检、镜头有来源、时长对得上。

## 0. 需求

```
产品：小青柑礼盒（新会三年陈，迪士尼联名）
要求：15s，9:16，画面 ≥5 个镜头，有字幕、有配音、有 BGM
```

## 1. 价值罗盘（先拆，再写）

| 支撑 | 内容 |
|---|---|
| 功能 | 一颗一泡，不用称茶；办公室 30 秒出汤 |
| 信任 | 新会核心产区三年陈；迪士尼联名；同类目销量第一（需截图凭证） |
| 情感 | 成年人的下午茶，是一个人待着的十分钟 |

主场景选 **办公 + 独处**（送礼场景另做一条，不要混）。

## 2. 先写草稿（draft 允许越线）

```
① 过完年饭局多，裤腰就松了
② 三年陈的小青柑，一颗一泡
③ 下午三点，办公室里泡一颗
④ 柑皮先香，茶汤后甜
⑤ 送人也体面，最高级的那种
```

体检（`--mode draft`）：

```
① causal-effect + koc-black-five   → 拆因果、去身体变化
⑤ absolute（最高级）                → 换成可查凭证或主观表述
```

## 3. 改写（三式）

```
① 并列式 → 过完年饭局多。下午那杯是我的开关。
⑤ 转述式 → 丈母娘喝过一次，后来每次去都问我带没带。
```

## 4. 终稿（逐句 + 画面 + 字幕）

| # | 文案（≤12 字） | 时长 | 画面（素材类型） | 字幕 |
|---|---|---|---|---|
| 1 | 过完年，饭局有点多 | 2.0s | 手部拆礼盒（包装） | 同句 |
| 2 | 下午那杯是我的开关 | 2.4s | 办公室冲泡（手部+电脑） | 同句 |
| 3 | 新会三年陈，一颗一泡 | 2.6s | 掰柑特写（产品） | 同句 |
| 4 | 柑皮先香，茶汤后甜 | 2.4s | 注水汤色（汤色近景） | 同句 |
| 5 | 丈母娘问我：带没带 | 2.8s | 递出礼盒 + 笑脸（人物/送礼） | 同句 |

```
合计口播 2.0+2.4+2.6+2.4+2.8 = 12.2s；加上句间换气 0.5–0.8s ≈ 13.0s
需要补 2 个呼吸点（0.8–1.0s）到 15s，或用空镜收尾（蒸汽 / 窗外）
镜头数：5 句 + 1 空镜 = 6 个，满足 ≥5
```

## 5. 元素 / BGM / 配音

```
元素：句间用「轻推」转场（不用闪白）；第 3 句压一行小字「新会 · 三年陈」
BGM ：温暖弦乐 + 轻打击，70–90 BPM；第 5 句起加一层弦乐
配音：女声，3.5 字/秒，句子之间停 0.25s
```


## 7. 检索清单（执行时用 agent 跑）

```

material.search  "小青柑 礼盒 开箱"           （送礼/开箱）
material.search  "小青柑 汤色 特写"           （汤色近景）
material.search  "小青柑 晒场"               （产地背书，备用）
library.search   kind=transition "轻推"       （转场）
library.search   kind=music "温暖 弦乐 轻快"   （BGM）
```

## 8. 这一份为什么能过

- 五句里全部是**事实 + 体感 + 别人的话**，没有一句建立因果；
- 没有任何功效词、病症词、绝对化；
- 每句都有具体动作（拆、泡、掰、注水、递）与可验证细节（三年陈、下午三点、丈母娘）；
- 画面对得上声音：句子 2.0–2.8s，镜头按句裁切，空镜只放在句间。
