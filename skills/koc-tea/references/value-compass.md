# 价值罗盘：把产品拆成能说的三块

写文案之前先填这张表。填不出来的格子，就是"写不出画面"的地方。

## 一、拆自己

| 支撑 | 要回答的问题 | 反例（不要这样写） | 正例 |
|---|---|---|---|
| 功能支撑 | 它解决哪个**场景问题**（不写功效） | 「祛湿养胃」 | 「一颗一泡，办公室 30 秒出汤」 |
| 信任支撑 | 我有什么你没有：产地/年份/工艺/联名/可查销量 | 「最好的新会陈皮」 | 「新会核心产区三年陈；迪士尼联名；某平台同类目销量第一（截图见详情）」 |
| 情感支撑 | 情绪、身份、精神价值 | 「喝了心情好」 | 「成年人的下午茶，是一个人待着的十分钟」 |

## 二、顾客与竞争视角

- **为什么买**：送礼体面 / 自己喝着舒服 / 办公室方便 / 长辈认这个 / 看别人喝想试
- **没被满足的需求**：不会泡、怕买贵、怕不正宗、怕难喝、怕麻烦
- **竞品都在说什么**：正宗新会、古法日晒、十年陈
  → 所以我们不再喊产地，差异要落在**场景与用法**（一颗一泡、办公室、送礼、独处）

## 三、翻译成标准文案（一张卡）

```
产品 / 版本：
场景（应用/动作）：
人物（谁、什么状态）：
前 3 秒钩子（现场声/动作/一句反常识）：
逐句文案（每句 ≤12 字）：
  1.
  2.
  3.
每句配的画面（素材类型：人物/手部/包装/汤色/环境/对比）：
字幕（与文案同句）：
元素（转场/贴纸/文字版式）：
BGM（情绪 + BPM 区间）：
配音（音色 + 语速）：
合规：draft 命中 → 已按 ___ 式改写 → publish 通过
```

## 四、四类常见产品的填法（示例）

| 产品 | 功能支撑 | 信任支撑 | 情感支撑 | 主场景 |
|---|---|---|---|---|
| 小青柑 | 一颗一泡、30 秒出汤 | 新会三年陈 | 独处的十分钟 | 办公 / 独处 |
| 闷泡茶（6 款） | 一个杯子里闷 3 分钟 | 产地 / 联名 | 待客体面 | 办公 / 待客 / 送礼 / 运动后 |
| 茉莉普洱 | 花香压住熟普的堆味 | 窖制次数 | 每天一杯的习惯 | 办公 / 独处 |
| 礼盒 | 开箱即饮/即泡 | 迪士尼联名、可查销量 | 关系里的体面 | 送礼 / 待客 |

## 五、自检三问

1. 这句话里有**具体动作**吗？（"我下午泡一颗"有；"很好喝"没有）
2. 有**可被第三方验证的细节**吗？（时间、地点、别人说过的话、物件）
3. 有没有建立**因果**？（有 → 拆成并列）
