# KOC 文案（通用层）

这一层只管**怎么说**，不管**卖什么**。品类红线在品类层（例如 `koc-tea`）。

## 什么时候用

- 写完一段口播，想确认能不能投；
- 平台判了"功效暗示 / 绝对化 / 诱导点击"，想知道怎么改；
- 需要一个不删内容、只换结构的改写起点。

## 三步

1. **体检**：`node check.mjs --mode publish --file script.txt`
   `publish` 会阻断（退出码 1），`draft` 只标注 —— 写草稿时用 draft，不必一开始就合规。
2. **看命中**：每条命中给出「平台原因 + 改法」。
3. **要候选**：加 `--rewrite` 得到三式，并标出哪个候选丢了锚点（⚠️）。

```
node check.mjs --rewrite --scene 办公 "喝了一个月，裤腰就松了"
```

## 三式（详见 references/rewrite-modes.md）

| 式样 | 做什么 | 例子 |
|---|---|---|
| 并列式 | 把"因为 A 所以 B"拆成两句并列的事实 | 喝了一个月。这个月的记录我留着。 |
| 转述式 | 结论交给第三方（同事/岳母/客户的话） | 同事问我：最近是不是喝了一个月？ |
| 场景式 | 只描述"什么时候、在做什么" | 办公，我喝了一个月 |

**锚点规则**：每个候选都必须保留一个动作（泡/开箱/送礼）或一个可验证细节（年份/产地/谁说的）。
没有锚点的句子就算合规也是空话，投放跑不动。检查器会标 ⚠️。

## 装到本机

```
node install.mjs --layer writer          # 只装通用层
node install.mjs --layer both            # 通用层 + 品类层
```
