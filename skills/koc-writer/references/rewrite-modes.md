# 改写三式（从命中项直接生成）

体检命中之后，不要删句子，**换结构**。三种式样覆盖绝大多数场合。

## 一、并列式（拆掉因果）

把"因为 A 所以 B"拆成两件并列的事实。

```
❌ 喝了一个月，裤腰就松了
✅ 我下午泡一颗。裤腰还是那条裤子。          （两句并列，不连成因果）

❌ 因为它，我的皮肤变好了
✅ 早上这杯热乎的先下肚。同事说我这阵子状态不一样。   （事实 + 别人的话）
```

判断标准：句子里没有"所以/就/才/让/使/因为"把两件事连起来。

## 二、转述式（把结论交给第三方）

自己的结论等于承诺；别人的疑问/评价等于观察。

```
❌ 喝完皮肤白了
✅ 同事问我最近是不是换了护肤品

❌ 送礼最体面
✅ 丈母娘喝过一次，后来每次去都问我带没带

❌ 喝了不胀
✅ 客户说"下午那杯下去，饭局前不那么顶了"
```

## 三、场景式（用应用场景承载）

不指向身体结果，只描述"什么时候、在做什么"。

```
❌ 祛湿
✅ 回南天，我每天早上泡这一颗

❌ 减肥
✅ 过完年饭局多，下午那杯是我的开关

❌ 助眠
✅ 晚上不喝咖啡了，改喝这个
```

---

## 改写质量自检（两条锚点）

改完必须仍然保留：

1. **一个具体动作**：泡、带、递、拍、收、拆；
2. **一个可被第三方验证的细节**：时间（下午三点/过完年）、地点（办公室/晒场）、
   别人的话（同事问我、丈母娘问我）、物件（那条裤子、那个礼盒）。

保不住这两条 → 你改的不是同一句话的安全版，而是另一句没有信息量的话。**这种改写等于失败。**

## 常见错误

| 错误 | 为什么错 | 正确做法 |
|---|---|---|
| 把"减肥"换成"轻盈" | 仍是功效暗示，且更含糊 | 换场景（"饭局多的时候"） |
| 全删成"好喝、香、回甘" | 没有信息点，完播率与转化双输 | 并列式加动作与细节 |
| 加"据说/听说" | 转述他人宣称同样算宣传 | 只说自己或具体某个人的观察 |
| 用"帮助/有助"软化 | 平台按语义判，"有助"仍是功效 | 换成并列的事实 |
