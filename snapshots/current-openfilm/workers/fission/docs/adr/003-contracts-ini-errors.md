# ADR-003 · ini 映射与错误文案契约

状态：已批准（评审 B4 · PRD v1.1/v1.2）

## 背景
UAT 要求报错文案与原版逐字一致、`多场景裂变.ini` 双向互换。链接附录不可测试；无映射规则会静默丢参。

## 决策
三件契约文件（`docs/contracts/`，git 版本化，测试断言对象）：

1. **error-messages.zh.json**：错误码 → 原版文案原文。引擎/UI/测试三方唯一事实源；UAT 逐字断言对它做，不对源代码做。
2. **ini-mapping-spec.md**：P0 键双向映射表（JSON 键 ↔ ini 键 ↔ 类型 ↔ 默认值）；**非 P0 键只读透传**（读入保留、回写原样），未知键写入"忽略清单"（report 呈现）——**不静默丢参**。
3. **align-strategies.json**：八策略真值表 + 16 组输入输出示例，单测表驱动。

## 后果
- 契约文件改动必须在 PR 中附对照说明（审查打回项）
- 与原版互操作范围冻结为 P0 参数面
