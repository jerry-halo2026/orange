# ADR-007 · 配音资产库（VoiceRegistry）

状态：已批准（Ethan 确认 · PRD v1.1.2；ADR-005 偏离三的具体化）

## 背景
「画面不同，配音相同也是一条新视频」——配音天然可按产品归类复用。原版用后即删把资产烧掉了，只留下防重复的副作用。

## 决策
- **资产库**：`generated/`（AIGC 产物：文案/标题/时长/字级时间戳/来源厂商/音色）+ `upload/`（自有配音，同 BGM 上传流水）；**归类维度 = 产品标签**（生成时自动挂、可手动归并）
- **usePolicy**：`once`（默认 = 原版）｜`count:N`（1–999，到 N 后删/归档/保留可选）｜`unlimited`（耐用品）
- **事务**：ADR-002 不变；确认消耗 = 计次 +1，**删除只是可选副作用**
- **循环驱动两模式**：消耗模式（音频池耗尽先到先停，parity）｜复用模式（停止由数量/素材不足/用户驱动；配音按产品随机/顺序取）
- **组合去重**：记录 `配音 hash + 画面组合 hash`，同配音同画面组合不重复出片——把原版删配音想防的"整条重复"防住，资产保留
- UI 每条显示累计已用次数（复用度操作员自判）

## 后果
- 素材池并发断言扩展：复用模式下 50 条成片零组合重复
- 平台音频指纹限流风险记 R7：亮数不劝阻
