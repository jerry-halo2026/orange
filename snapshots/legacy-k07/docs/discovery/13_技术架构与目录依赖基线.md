## 5 编译依赖与运行通信

### 5.1 编译依赖白名单

| 消费者 | 允许依赖 | 禁止依赖 |
| --- | --- | --- |
| contracts | 无平台副作用的Schema/验证支持库 | React/Electron、数据库、供应商SDK及业务实现包 |
| ui | React/公共样式，必要契约类型 | main/preload/application实现、数据库、文件系统、供应商SDK |
| renderer | ui、contracts、批准的桥接客户端；creation可用film-adapter/renderer | application/node入口、Electron特权API、fs、云端模块或密钥 |
| preload | Electron最小桥接、contracts/验证器 | 任意命令/文件直通、全量服务对象、用户工程代码 |
| application | contracts及本地用例端口定义 | React/Electron、film内部、数据库SDK和云端实现；通过注入端口使用能力 |
| main/受控宿主 | application、contracts及node适配器，提供存储/文件/worker/服务端口 | 主线程重渲染/推理，公司高权限云密钥 |
| film-adapter | contracts；renderer接批准Studio UI，node接批准本地Studio/格式入口 | renderer的barrel导出夹带node代码；vendor反向依赖橙子业务 |
| jianying-adapter | contracts及node媒体/格式支持 | UI、云端积分/绑定、当前可变编辑头；只消费固定快照 |
| api | contracts、服务端模块及受控基础设施/供应商适配 | desktop/ui、vendor本机宿主、Fission二进制或本地application实现 |
| Fission worker | 原.NET依赖、contracts同版本生成协议/样例 | TS运行时包、个人云凭据、直写共享历史/积分或私人工程库 |

实际允许入口/路径由T02签发消费冻结；同名DTO不能绕过注册表。浏览器构建不得含node/密钥代码，依赖图不得成环，也不因“只读一次”跨模块读取内部表。

### 5.2 运行时方向

```text
橙子页面/film宿主 → 最小桥接 → 本地应用用例
本地应用用例 → Studio工作进程 / Fission工作进程 / 交付适配
本地应用用例 → 橙子Node/TS API → Postgres及本人范围智尚/模型服务
结果/事件 → 幂等核对 → 本地持久任务 → UI显示
```

不是所有操作都走云：本地保存、编辑和已准入有权任务按C40/C85续跑；启动/重启在线鉴权，新组合在线批准。媒体字节用受控文件引用/流，不塞JSON事件；执行边界验证路径、版本与使用权。

Studio原有loopback服务不能仅因localhost就默认可信：调用来源/凭证、允许目录和资源访问须统一收口。Fission优先适配可验证既有接口，明确消息版本、取消/退出、产物证据、背压与日志分流，实际通道在T02签发，不捏造已存在命令。

用户/Agent生成的film.html及页面脚本是待校验输入，不得继承壳体Node、桥接、令牌、文件或网络权限。受控编辑也遵守expectedRevision、人审和撤权；进程隔离不是任意脚本可安全执行的保证。

- 不为统一语言重写.mjs或.NET，也不默认装Python。额外剪映/分析运行时先审依赖、分发、安全和维护证据，再走技术变更，不自动把参考仓库打包进客户端。
