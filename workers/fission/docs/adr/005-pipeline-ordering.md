# ADR-005 · 管线次序决策（三处声明偏离原版）

状态：已批准（Ethan 裁决 · PRD v1.2 · 2026-11-03）

## 偏离一：抽帧前置到时长对齐之前
- 原版：抽帧属视觉差异化，在 AV 合并后执行——时长缩短、播放加速、音画漂移（原版 UI 自己带警示文案）
- 我们：抽帧在片段级（SCENE_SPLIT 后、ALLOCATE 前）执行，抽帧比例可精确折算时长系数，对齐按抽帧后实际时长计算 ⇒ 时长与音画同步由八策略保证
- 断言：抽帧+对齐集成测试，输出时长 = 目标 ±1 帧

## 偏离二：快速模式 + 转场自动降级标准模式
- 原版：极速模式（concat -c copy）与转场（必然重编码的 GL 通道）未组合
- 我们：组合矩阵显式化——快速+转场自动降级标准模式，UI 勾选即时提示，日志记降级事件

## 偏离三：配音资产化（原版用后即删 → VoiceRegistry）
- 原版删配音的真实意图 = 防整条成片重复；副作用 = 资产一次性消耗
- 我们：防"整条重复"改由**组合去重**（配音 hash + 画面组合 hash 不重复）承担；配音按 usePolicy（once/count:N/unlimited）复用，详见 ADR-007
- 证据：原厂隐藏行为「重复抽取+随机+用过不删除 ⇒ 无数视频」自证了该玩法成立

## 后果
- parity 模式仍可表达：usePolicy=once + 抽帧关 + 快速无转场 = 原版行为
- 三处偏离均写入 UAT 组合用例
